## docker logs

```sh
## 查看容器日志 类似于tail的查看 有新的就刷新出来
docker logs -f [容器id]

## 查询容器能包含某个url的日志内容
docker logs [容器id] | grep  '/url' -[A|B|C] 100
## -A After grep到的前面的100行
## -B Before 后面的100行
## -C Context 上下文 100行
    
```    

## docker images

```sh
## 批量清理镜像 同理可以批量清理容器
docker images | grep "wtp-user" | awk '{print $3}' | xargs -r docker rmi -f 
```

## docker stats

```shell
## 实时刷新的容器cpu内存使用情况
docker stats
## 单词快照
docker stats --no-stream
```

## docker ps

```sh
docker ps -q -a --filter name=aaa --filter label=key=value --filter ancestor=xxx 
## -a 所有
## -q quiet 只显示containerId
## --filter name=xxx 过滤容器名是aaa前缀(右模糊)
## --filter label=key=value 过滤容器标签有key对应的value
## --filter ancestor=xxx  过滤镜像名称是xxx的(精确匹配)

```
