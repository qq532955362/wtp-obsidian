## 页面有权限设计
分为无需登录的页面，需要登录状态的页面，和需要权限的页面
权限在jwt的payload中的authority(字符串数组)字段

### 这是jwt的payload中的额外字段：

```json
{
    "id":1,
    "authority":["ROLE_ADMIN"],
    "nickname":"wtp"
}
```


## 有后台管理 路由在/admin
### 后台管理需要登录（有注册）
要求使用better-auth然后使用账号（邮箱）密码（限制需要数字 大写字母 小写字母 特殊符号）
要求需要登录的页面需要验证jwt是否存在且有效
要求不需要登录
