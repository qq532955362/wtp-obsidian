# X10系列车载音响主机后面板接口说明

根据X10 Flagship Series车载音响用户手册，后面板集成了多种接口，不同型号略有差异。以下是详细的接口说明：

## 一、主要接口概览

X10系列后面板包含以下核心接口：

| 接口类型 | 接口名称 | 功能说明 |

|---------|---------|---------|

| 电源 | Power 15A | 20针电源电缆供电 |

| 音频输出 | RCA | 多通道音频输出和AV输入 |

| 视频输入 | Mini HDMI-IN | 高清视频和音频输入 |

| 天线 | FM-ANT | 收音机天线输入 |

| 天线 | DAB-ANT | 数字音频广播天线（可选） |

| 天线 | GPS/4G/WiFi-ANT | GPS/4G/WiFi天线 |

| 存储 | USB1 | DVR存储 |

| 存储 | USB2 | 外部存储 |

| 音频输出 | Optical SPDIF-OUT | 光纤音频输出 |

| 麦克风 | MIC | 外部麦克风输入 |

| 摄像头 | DVR | 行车记录仪输入 |

| 音频 | 3-WAY-A | 三分频音频输出 |

## 二、音频接口详解

### 1. RCA端口

- **用途**：提供多通道音频输出和AV（音频/视频）输入

- **适用型号**：X10G110E, X10G110PE, X10G125E, X10G129E, X10G129PE, X10G141E

### 2. 低音炮输出

- **SUBR Output**：右低音炮输出

- **SUBL Output**：左低音炮输出

### 3. 声道输出

- Front Left Audio Out（前左声道输出）

- Front Right Audio Out（前右声道输出）

- Rear Left Audio Out（后左声道输出）

- Rear Right Audio Out（后右声道输出）

### 4. 辅助音频输入

- Left Channel Auxiliary Audio Input（左声道辅助音频输入）

- Right Channel Auxiliary Audio Input（右声道辅助音频输入）

## 三、视频与摄像头接口

### 1. 视频输入

- **Mini HDMI-IN**：允许从外部设备输入高清视频和音频

### 2. 摄像头输入

- **RCAM**：后摄像头输入

- **IFCAM**：前摄像头输入

- **Rear DVR Camera Input**：后DVR摄像头输入

- **Front DVR Camera Input**：前DVR摄像头输入

## 四、其他功能接口

### 1. 控制接口

- **Steering Wheel Audio Control (SWC)**：方向盘音频控制（连接到AC-44F60）

- **FUSE**：车载音响保险丝

### 2. 网络与定位

- **4G LTE**：4G LTE适配器接口

- **GPS/4G/WiFi-ANT**：GPS/4G/WiFi天线接口

### 3. 3.5mm接口

- **3.5mm Jack**：3.5mm音频接口（如适用）

| 接口图类型 | 适用型号 |

|-----------|---------|

| 类型一 | X10G110E, X10G110PE, X10G125E, X10G129E, X10G129PE, X10G141E |

| 类型二 | X10G209E, X10G211E, X10G225E, X10DG209E, X10DG211E, X10G2A7E, X10G2B7E, X10DG2B7E, X10G2D7E |

---

**注意事项**：

1. 不同型号的接口布局可能略有差异，请根据具体型号确认

2. DAB-ANT为可选接口，部分型号可能不支持

3. 3.5mm Jack接口仅在部分型号上提供

4. 连接前请确保电源关闭，避免短路损坏设备
